# DeyounApp v1.5

## الجديد في v1.5
- واجهة جديدة بأيقونات وشريط تنقل سفلي: الرئيسية • العملاء • التنبيهات • المزيد.
- فصل الشاشة الرئيسية عن قائمة العملاء.
- قسم «العملاء»: بحث وتصفية، ولكل عميل أول قسط مستحق وآخر قسط، وعند فتح ملفه جدول الأقساط (التاريخ والمبلغ والحالة) مع تسجيل دفعة جديدة.
- قسم «التنبيهات»: الأقساط المتأخرة والمستحقة اليوم وخلال 7 أيام، مع تسجيل دفعة واتصال بالعميل.
- تاريخ أول قسط لكل سلعة (يُختار من التقويم)، والأقساط شهرية.
- دليل استخدام مفصل (المزيد ← دليل الاستخدام) مع أيقونة (؟) تشرح كل قسم.
- لم يتغير تركيب قاعدة البيانات: بياناتك والنسخ الاحتياطية القديمة تعمل كما هي.
