# تطبيق إدارة الديون والأقساط — النسخة الأولى

تطبيق Android عربي يعمل محلياً على الهاتف.

## الوظائف الحالية
- إضافة العملاء والاسم والهاتف والعنوان.
- عرض إجمالي الديون والمدفوع والمتبقي.
- فتح ملف العميل بالضغط على اسمه.
- إضافة عدة سلع/عقود تقسيط للعميل.
- تسجيل السعر الأصلي وسعر التقسيط والربح.
- تحديد عدد الأقساط وقيمة القسط، أو حساب القسط تلقائياً.
- تسجيل الدفعات وتحديث المتبقي تلقائياً.
- عرض سجل دفعات كل سلعة.
- حساب عدد الأقساط المتبقية تقريبياً.

## التشغيل
افتح مجلد المشروع في Android Studio ثم اختر Gradle Sync وبعدها Run.
يتطلب Android Studio حديثاً وSDK 35. المشروع يستخدم Java وAndroid SDK مباشرة لتقليل الاعتماديات.
