# DeyounApp v1.4

## الجديد في v1.4
- نسخ احتياطي تلقائي إلى محادثتك الخاصة مع بوت تيليجرام (القائمة ← النسخ التلقائي).
- يُرسل التطبيق نسخة بعد كل تعديل على البيانات (بحد أقصى مرة كل 5 دقائق)، وإذا لم يتوفر الإنترنت يعيد المحاولة تلقائياً.
- يفحص التطبيق سلامة النسخة قبل إرسالها، ويحتفظ تيليجرام بجميع النسخ السابقة.
- الاستعادة: نزّل آخر ملف .db من محادثة البوت، ثم النسخ الاحتياطي ← استعادة.
- أيقونة جديدة للتطبيق.
