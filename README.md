# DeyounApp v1.3

تطبيق Android عربي لإدارة الديون والأقساط.

## الجديد في v1.3
- واجهة رئيسية أحدث وأكثر وضوحاً.
- شريط جانبي (قائمة) للوصول إلى الرئيسية والعملاء والأقساط والتقارير والنسخ الاحتياطي.
- زر رجوع واضح داخل ملف العميل ودعم زر الرجوع في الهاتف.
- إعادة تصميم ملف العميل وبطاقات المشتريات.
- أزرار تعديل وحذف واضحة للعميل والسلعة.
- نافذة تأكيد قبل الحذف.
- سجل دفعات منفصل لكل سلعة.
- استمرار دعم النسخ الاحتياطي والاستعادة.
